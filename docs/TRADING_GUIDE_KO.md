# Penny Stock Radar 판단 기준

이 문서는 대시보드와 자동화 결과를 읽을 때 무엇을 우선 확인해야 하는지, 그리고 `조건부 진입 / 재료 확인 전 / 눌림 대기 / 추격 금지` 같은 라벨을 어떻게 해석해야 하는지 정리한 기준 문서입니다.

## 큰 흐름

1. `전체 후보군`
2. `프리장 전 분석`
3. `프리장 중 분석`
4. `정규장 분석`
5. `실시간 모드`

핵심은 `급등 자체`보다 `공개 재료`, `거래대금`, `스프레드`, `구조 유지`를 함께 보는 것입니다.

## 단계별로 먼저 볼 것

전체 후보군:

- `passed_filters`
- `filter_reasons`
- `price`
- `market_cap`
- `float_shares`

프리장 전 분석:

- `total_score`
- `catalyst_score`
- `technical_score`
- `sympathy_score`
- `social_score`

프리장 중 분석:

- `quality_score`
- `dollar_volume`
- `premarket_rvol`
- `spread_pct`
- `tape_anomaly`

정규장 분석:

- `decision`
- `anchored_vwap`
- `extension_z`
- `mfe_pct`
- `mae_pct`

## 라벨 해석

`조건부 진입`:

- 모멘텀, 거래대금, 스프레드, 기존 레이더 맥락이 함께 맞는 경우
- 즉시 추격이 아니라 `첫 눌림 후 재돌파` 기준으로 해석

`재료 확인 전`:

- 가격과 유동성은 강하지만 공개 재료가 아직 확인되지 않은 경우
- 뉴스, 공시, filing 확인 전 신규 진입 보류

`눌림 대기`:

- 힘은 있으나 구조 확인이 더 필요한 경우
- VWAP 회복, 분봉 고점 재돌파, 시초 range 유지 등을 확인

`추격 금지`:

- 스프레드, 거래대금, 과확장, 모멘텀 약화 중 하나 이상이 문제인 경우
- 방향이 맞아도 손익비와 체결 품질이 나쁜 상태

## 핵심 원칙

1. 상승률만으로는 진입 근거가 부족합니다.
2. 거래대금과 스프레드는 진입 신호가 아니라 실행 가능성 필터에 가깝습니다.
3. 공개 재료 맥락이 없으면 보수적으로 해석합니다.
4. 불타기는 수직 추격이 아니라 확인 후 추가여야 합니다.

## 한 줄 요약

- 전체 후보군: 볼 가치가 있는 종목만 남기는 1차 필터
- 프리장 전 분석: 오늘 볼 종목을 압축하는 단계
- 프리장 중 분석: 지금 뜨는 종목이 진짜인지 거르는 단계
- 정규장 분석: continuation인지 fade인지 최종 판단하는 단계

## 자동화 리뷰에서의 사용법

- actionable 종목보다 `blocked 이유`, `daily loss lock`, 데이터 품질 문제를 먼저 봅니다.
- live mover 해석은 이 문서 기준으로 일관되게 씁니다.
- 과장된 매수 표현보다 `확인 필요`, `보류`, `구조 미흡` 같은 보수적 표현을 우선합니다.
